CachyOS
=======

Note: I Ubuntu LTS, Fedora and .... before landing on CachyOS.  It seemed to have the best support
for the Nvidia drivers.

However, CachyOS installs by default with BTRFS file system which seems to not play nicely with nanochat.

The ext4 file system is more compatible with nanochat (although XFS may be better)

Also, using KFCE desktop as it is much lighter weight than GNOME.

Update after install:



Need to install:

* Git
* OpenSSH
* Screen
* Nvidia SMI
* GDB
